D7 — tratamiento de FAIL

Ejecutar todos los gates preregistrados cuando técnicamente sea posible.

Un FAIL lógico no corta automáticamente los otros tests baratos.

Hard-stop solamente si ocurre:

Plain text
CUDA/runtime crash
structural corruption
unrecoverable OOM
non-finite state que impide ejecutar el siguiente gate

En ese caso se marca el resto NOT_RUN_DUE_TO_HARD_STOP.

Al final:

Plain text
cualquier required gate FAIL
→ OMEGA_V2_2A_LOCAL_PREFLIGHT_FAIL

Sin segunda corrida con LR/seeds/tolerancias distintos bajo el mismo ID.

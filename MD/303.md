4. Bloque recurrente contractual exacto
4.1 Entrada y estado

El core aislado recibe:

[
S_r \in \mathbb{R}^{B\times m\times d}
]

donde:

B = batch
m = número de slots del workspace
d = anchura del core
r = ronda recurrente

Valores contractuales de esta unidad:

d ∈ {512, 640}
m ∈ {4, 8, 16}
K = entero runtime, no dimensión paramétrica

El core no contiene embedding léxico, tokenizer, head de vocabulario, memoria externa ni retriever.

4.2 Normalización

Para mantener literal el ledger 16d², V2-0 usa RMSNorm sin parámetros aprendibles:

[
RMS(x)=\frac{x}{\sqrt{\operatorname{mean}(x^2)+\epsilon}}
]

con:

epsilon = 1e-6
learned gamma = NO
bias = NO

Cualquier RMSNorm aprendido, bias, gate aprendido, depth embedding o parámetro adicional deberá ir en una unidad posterior y en un ledger separado. No puede introducirse silenciosamente en V2-0.

4.3 Slot attention — 4d²

Para cada ronda:

[
X = RMS(S_r)
]

[
Q=XW_Q^T,\quad
K=XW_K^T,\quad
V=XW_V^T
]

con:

W_Q : [d,d]
W_K : [d,d]
W_V : [d,d]
W_O : [d,d]
biases: none

La atención de referencia V2-0 es sobre los m slots:

[
A=
\operatorname{softmax}
\left(
\frac{QK^T}{\sqrt d}
\right)V
]

[
H=S_r + AW_O^T
]

Conteo de matrices:

[
d^2+d^2+d^2+d^2=4d^2.
]

V2-0 usa una semántica de referencia de single-head full-d para eliminar ambigüedad funcional. El contrato de parámetros 4d² no depende de esta elección. Cualquier futura división multi-head debe declararse antes de resultados; no se inferirá retrospectivamente que V2-0 la validó.

No hay causal mask entre slots: los slots son workspace, no posiciones temporales de texto.

5. MLP contractual exacta — 12d²

La MLP que asumo para hacer literal el contrato de Conversacion.md es:

SwiGLU con hidden = 4d y tres matrices sin bias.

Sea:

[
Z=RMS(H)
]

Matrices:

W_gate : [4d, d]
W_up   : [4d, d]
W_down : [d, 4d]
biases : none

[
G=ZW_{gate}^{T}
]

[

]

\operatorname{SiLU}(G)\odot U
\right]

[

]

[

16d^2.

7. K-flex — condición estructural obligatoria

K debe ser un argumento runtime.

Forma:

state = input_state
for _ in range(K):
    state = shared_block.step(state)
return state

Prohibido en V2-0:

depth_embedding[K, d]
gate_logits[K, d]
round_embeddings[K, ...]
K bloques precreados para la variante recurrente
cualquier parámetro cuyo shape dependa de K
cualquier fallback TAIL-REPEAT
creación lazy de parámetros cuando K aumenta

Requisitos:

K >= 1
m >= 1
state_dict independiente de K
P_core_unique independiente de K
m independiente del número de parámetros

Acceptance K de esta unidad:

K ∈ {1,2,4,8,16}

El mismo objeto recurrente y exactamente los mismos pesos deben ejecutar todos esos K.

No se implementa halting aprendido en V2-0.

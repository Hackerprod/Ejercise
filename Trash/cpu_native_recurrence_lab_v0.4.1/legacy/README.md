# Legacy probes

Los archivos en `original_probes/` se conservan únicamente para trazabilidad histórica. No se compilan ni se enlazan.

Contienen varios problemas ya documentados: conteos inflados, variantes A/B con contenido distinto, transición serial, kernels cambiados entre gates, autotests dentro del proceso cronometrado y métricas de ancho de banda ambiguas. No deben usarse como fuente autoritativa de resultados.

10. Metric correction

The current draft still leaves the principal normwise metric reference-conditioned.

Because Stage A exists specifically to design a well-conditioned Stage-B comparator, replace §5 primary normwise definitions with symmetric forms.

Let:

c = candidate
r = scalar-Q4
delta = c-r

All reductions performed in FP64.

Primary normwise L2

[
E_{L2}=
\frac{|\delta|_2}
{\max(|c|_2,|r|_2)}
]

If both norms are exactly zero:

E_L2 = 0
both_zero = true
Primary normwise infinity

[
E_{\infty}=
\frac{|\delta|\infty}
{\max(|c|\infty,|r|_\infty)}
]

Same both-zero rule.

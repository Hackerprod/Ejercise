El binario standalone con goldens por archivos es excelente para correctness, pero no puede ser la ruta principal del benchmark de entrenamiento.

No podemos hacer:

Ese gradiente no existe hasta que el resto del modelo haya hecho forward con los pesos de ese update.

El adaptador PyTorch es deliberadamente desechable

Esto es la parte que resuelve la objeción histórica.

No estaríamos diciendo:

“El runtime final es una extensión PyTorch.”

Sino:

“Durante la migración usamos PyTorch como banco de pruebas para una biblioteca que ya es completamente independiente.”

La cantidad de código descartable debería ser mínima, quizás cientos de líneas como máximo y sin matemática propia.

Regla:

NO recurrent equation may exist in the PyTorch adapter.

Adapter responsibilities only:
    validate tensors
    allocate outputs/workspace
    populate pointer descriptors
    call DLL
    translate native status
    return gradients

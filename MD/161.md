Una corrección al benchmark GPU

No mediría sólo un update por configuración.

Eso sería insuficiente porque el contrato causal alterna:

update 0 → window 0
update 1 → window 1

y window 1 tiene:

estado persistente procedente de window 0;

teacher con prefijo de 512;

ruta de memoria/cómputo distinta.

Por tanto, una medición que sólo mida update 0 podría elegir B=8 con una fotografía incompleta.

Para cada configuración A/B/C exigiría unidades completas 0→1.

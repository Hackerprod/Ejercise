El criterio para decidir si seguimos

Predeclararía algo como esto.

Después del profiling + compile:

Si CPU PyTorch optimizado ya baja SCOPE-A a <= ~24 h:
    NO construir custom trainer todavía.
    ejecutar scoping.

Si sigue ~40–60 h pero el core R1 representa >=25–30%:
    probar custom T0 forward op.

Si custom T0 op logra >=20% end-to-end:
    considerar custom backward después del scoping.

Si logra <10% end-to-end:
    cerrar T0-training como NO_PRIORITARIO.

La cifra importante es end-to-end, no:

“mi GEMV es 8× más rápido”

Un kernel 8× más rápido que representa 10% del update apenas cambia el entrenamiento completo.

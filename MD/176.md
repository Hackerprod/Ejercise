Mecánica autoregresiva exacta

Para cada prompt:

Estado recurrente inicial = cero.

Pasar los 32 tokens del prompt una sola vez por forward_window.

Los logits de la última posición predicen el primer token nuevo.

next_token = argmax(last_logits).

Alimentar ese token como [1,1] junto con el estado final anterior.

Repetir token por token, manteniendo el estado.

Cada prompt nuevo vuelve a estado cero.

Eso prueba realmente el régimen free-running del modelo, no teacher forcing.

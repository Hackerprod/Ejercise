Qué puede concluir SCOPE-A

No puede declarar:

OMEGA PASS
Δ_depth >= 0.05 confirmado
20k innecesarios
5 seeds innecesarias

Sí puede responder:

¿Hay una señal reproducible temprana de que shared_K4 aprende mejor lenguaje que shared_K1?

En cada checkpoint calculamos, por seed:

Δdepth,i(u) = NLL K1,i(u) − NLL K4,i(u)

y mostramos las dos curvas completas.

Antes de ver resultados, dejo esta clasificación simple:

PROMISING
  Δ_depth(2000) > 0 en ambas seeds
  y la media pareada > 0

NO_SIGNAL
  Δ_depth(2000) <= 0 en ambas seeds
  y la media <= 0

MIXED
  cualquier otro caso

PROMISING permite plantear SCOPE-B hasta 5k. NO_SIGNAL pone SCOPE-B en HOLD. MIXED no autoriza automáticamente más entrenamiento: se analiza la trayectoria 0→500→1000→1500→2000 antes de decidir. No añado ahora un umbral artificial de +0.02/+0.03, porque no tenemos base empírica para decidir a qué fracción del gate final debería haber llegado R1 exactamente a 2k updates.

Y el gate formal continúa intacto:

Δdepth ≥ 0.05

para la campaña confirmatoria, no para este screening. La estrategia de scoping ya estableció precisamente esa separación.
